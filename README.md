# Trung Nguyen · UX/UI Design Portfolio

Static editorial UX/UI Design portfolio built with design tokens (`tokens.css`), zero external frameworks, and five end-to-end case studies:

1. **Djaminn** (Music Collaboration App · UI & Material 3 Design System)
2. **BMW Online Service Booking AI** (Automotive AI · Conversational UI)
3. **Pentana Solutions · Reporting** (Enterprise SaaS · UI & Angular Front-end)
4. **Pentana Solutions · Registration** (Enterprise SaaS · Adaptive 5-Step Flow)
5. **Zonie** (Personal Project · Solo Product, Design System & AI Front-end + live interactive HTML prototype)

## Local preview

```bash
python3 -m http.server 8080
# Open http://localhost:8080
```

## Publish on GitHub Pages

1. Push `main` branch to `https://github.com/trungnguyenminh1994-cell/trung-nguyen-portfolio`.
2. In GitHub **Settings -> Pages**, choose **Source: GitHub Actions** (uses `.github/workflows/pages.yml`) or **Deploy from a branch (`main` / root)**.
3. Live URL: https://trungnguyenminh1994-cell.github.io/trung-nguyen-portfolio/
