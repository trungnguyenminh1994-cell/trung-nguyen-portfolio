# Trung Nguyen · UX/UI Design Portfolio

1. **Djaminn** (Music Collaboration App · UI & Material 3 Design System)
2. **BMW Online Service Booking AI** (Automotive AI · Conversational UI)
3. **Pentana Solutions · Reporting** (Enterprise SaaS · UI & Angular Front-end)
4. **Pentana Solutions · Registration** (Enterprise SaaS · Adaptive 5-Step Flow)
5. **Zonie** (Personal Project · Solo Product, Design System & AI Front-end + live interactive HTML prototype)
