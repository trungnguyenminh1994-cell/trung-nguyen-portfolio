Design notes

  • Map uses Leaflet + CARTO Voyager tiles (free, no key needed), real Ho Chi Minh City coordinates.
  • Tap empty space on the map to try the create-zone flow. It includes a home-address warning and real reverse-geocoding via Nominatim.
  • Inside a zone, each contributor has their own board. Zoom into one board until it's the only one on screen and it focuses (pink border); zoom out to see several and none focus.
  • Try the 4 tools at the bottom: 📷 photo, 🏷️ sticker, ✏️ draw, Tt text. All draggable and resizable.
  • Notes inside your own board can be dragged anywhere, freely.

This is a simulation for reviewing UX/UI. Data only persists in the browser; placeholder images come from Picsum (free).
